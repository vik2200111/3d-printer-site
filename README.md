# VOXEL FORGE — терминал 3D-печати (статическая версия для Render.com)

Адаптация проекта [vik2200111/3d-printer](https://github.com/vik2200111/3d-printer) под размещение
на **Render.com** без сервера и базы данных.

Оригинал был на Next.js + PostgreSQL (авторизация и заказы через БД). Эта версия — полностью
клиентское приложение (React + Vite + Tailwind CSS): авторизация и заказы хранятся в
`localStorage` браузера, 3D-вьюпорт рисуется на Canvas без three.js. Поэтому сайт собирается
в обычную статику (`dist/index.html` — один файл) и размещается на бесплатном **Static Site** Render.

## Что есть на сайте

- **Мастерская**: 3D-вьюпорт (изометрия, вращение мышью, «живая» печать слоями), 4 пресет-модели,
  загрузка своих `.STL` / `.OBJ` (парсинг и расчёт объёма в браузере), слайдеры сглаживания и
  заполнения, 5 материалов и 6 цветов пластика, калькулятор стоимости с наценкой +20%.
- **Личный кабинет**: вход/регистрация (localStorage), заказы со стадиями
  «выбрана → к оплате → в очереди → печатается → готово», авто-тик симуляции принтера каждые 3.5 с
  и ручная кнопка ускорения.
- Кибер-терминальный UI, звуковые эффекты (WebAudio), тосты-уведомления.

## Локальный запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка статики в dist/
```

## Деплой на Render.com (вариант 1 — Blueprint, рекомендуется)

1. Залейте этот проект в свой GitHub-репозиторий.
2. На [render.com](https://render.com) → **New → Blueprint** → выберите репозиторий.
3. Render подхватит `render.yaml` и создаст Static Site автоматически.
4. Готово: сайт будет доступен по адресу вида `https://voxel-forge.onrender.com`.

## Деплой на Render.com (вариант 2 — вручную)

1. **New → Static Site** → подключите GitHub-репозиторий.
2. Настройки:
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
3. Нажмите **Create Static Site**.

Никаких переменных окружения (env) не требуется — проект полностью статический.

## Деплой на любой другой статический хостинг

Любой хостинг, который умеет раздавать папку `dist/` после `npm run build`, подойдёт
(GitHub Pages, Netlify, Vercel, Cloudflare Pages и т.д.). Для SPA-маршрутизации добавьте
rewrite `/* → /index.html` (в `render.yaml` он уже прописан).
